# ✈️ TravelAnks — Travel Booking System

A simple and interactive travel-booking website built using **HTML, CSS, and JavaScript**. TravelAnks allows users to explore popular destinations, calculate estimated trip costs, manage bookings, and maintain registered traveler details through a user-friendly interface.

## 📌 Project Overview

TravelAnks is a front-end web development mini project designed to simplify the travel-planning process. It brings destination exploration, booking management, and traveler record management together in one website.

## ✨ Features

- 🌍 **Destination Exploration** — Browse popular Indian travel destinations, including Goa, Manali, Jaipur, Kerala, Mumbai, Delhi, Udaipur, and Rishikesh.
- 📝 **Booking Form** — Enter travel details to plan a trip.
- 💰 **Estimated Price Calculation** — Calculate the estimated cost based on booking details.
- ✅ **Booking Summary & Confirmation** — Review booking information and confirm trip details.
- 👥 **Registered Traveler Management** — View registered travelers in a table.
- ✏️ **Update Traveler Details** — Edit a traveler's location.
- 🗑️ **Delete Traveler Records** — Remove traveler entries when required.
- 🎨 **Interactive User Interface** — Explore destinations and manage travel details through a visually appealing website.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- A web browser such as Google Chrome.
- Visual Studio Code (recommended).

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/anks03/TRAVEL_BOOKING-SYSTEM.git
```

**2. Navigate to the project folder**

```bash
cd TRAVEL_BOOKING-SYSTEM
```

**3. Open the project**

Open the folder in Visual Studio Code.

**4. Run the website**

Open `index.html` in your browser, or use the **Live Server** extension in VS Code for a better development experience.

No additional package installation is required for this HTML, CSS, and JavaScript project.
